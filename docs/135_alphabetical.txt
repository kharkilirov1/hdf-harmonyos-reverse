3. ВЫВОД/ПЛАН
   A. Теперь, когда BMS РАБОТАЕТ (bms.ready ставится, db создаётся,
      install работает), самый прямой путь — самим поставить SceneBoard
      через `bm install -p /system/app/SceneBoard/SceneBoard.hap`,
      дождавшись bms.ready. Раньше это было невозможно (BMS была мертва).
   B. Схема bmrun:
        - sync-цикл;
        - ждать `param get bootevent.bms.main.bundles.ready` == true
          (или таймаут 1500 c);
        - `bm install -p /system/app/SceneBoard/SceneBoard.hap`
          (логи в файл; при успехе — маркер в консоль);
        - затем `aa start` для SceneBoard не подойдёт (это
          ExtensionAbility) — старт выполняет appfwk как
          startup-extension; возможно потребуется `param set
          bootevent...`/перезагрузка, но сначала проверить, не начнёт
          ли appfwk сам поднимать SceneBoard после установки.
   C. После успешной установки проверить:
        - /data/app/el1/bundle/public/com.ohos.sceneboard
        - процесс ohos.sceneboard в консоли init (started info ...)
        - bootevent.launcher.ready == SET
