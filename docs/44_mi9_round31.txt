=== 44. Раунд 31: Распознан формат Parcel в binder-транзакциях к samgr ===

Дата: 2026-10-27. Продолжение 43_mi9_round30.

═══════════════════════════════════════════════════════════════════════
ЧТО СДЕЛАНО
═══════════════════════════════════════════════════════════════════════

1) В binder.c добавлен дамп первых 24 слов payload для транзакций от
   процесса foundation к samgr (FNDTXN: code, размер, слова d0..d23).

2) РАСШИФРОВАН ФОРМАТ PARCEL (по дампам):
     d0 = 0x00000100        — заголовок parcel
     d1 = 0               — флаги
     d2 = 0x00000016 (22) — длина UTF-16 строки дескриптора
     d3..d14              — UTF-16 "ohos.samgr.accessToken"
                            (0068 006f 0073 006f 0073 002e 006d 0061
                             0072 0067 0061 002e 0063 0063 0073 0065
                             0054 0073 006b 006f 006e 0065)
     далее:
       code=10 sz=92:  d15=0x00000c84=3204  -> SA id 3204
                       d16=0x0000000a=10, затем UTF-16 "foundation"
                       (deviceId)
       code=12 sz=68:  d15=0x00000f3d=3901  -> SA id 3901
       code=20 sz=112: d15=0x0000000a, d16.. — строка "foundation"

3) ВЫВОД: поле SA id найдено (word 15 после дескриптора), code=10 —
   CheckSystemAbility/GetSystemAbility, code=12 — аналогичная операция
   для другого API (SA id 3901). Это объясняет поток code=12 от
   hilogd/cadaemon/audio_server — это НЕ AddSystemAbility.

═══════════════════════════════════════════════════════════════════════
СОСТОЯНИЕ
═══════════════════════════════════════════════════════════════════════

- Формат Parcel расшифрован, можно искать конкретный код AddSystemAbility
  по SA id в payload (например, найти транзакцию с id 4607/1912,
  которая непосредственно предшествует "insert SA:...", и зафиксировать
  её code; затем искать code с id=401).
- Пока insert SA:401 отсутствует (как и во всех прогонах), публикации
  BMS нет.

═══════════════════════════════════════════════════════════════════════
СЛЕДУЮЩИЙ ШАГ (если продолжаем)
═══════════════════════════════════════════════════════════════════════

Запустить прогон с дампом всех foundation->samgr транзакций (без капа
или с большим), найти транзакцию с SA id 4607/1912/403/4005 и её code =
AddSystemAbility; затем тем же фильтром искать 401. Если транзакции
с 401 нет — окончательно подтверждается, что BMS не вызывает
AddSystemAbility (и единственный путь — инъекция вызова Publish в
libbms). Если есть — смотреть точку отказа в samgr.
