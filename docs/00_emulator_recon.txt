[ARCHITECTURAL FINDING]
CONFIG_DRIVERS_HDF=n in emulator kernel.
-> uhdf runs but without kernel backend.
-> Phone has CONFIG_DRIVERS_HDF=y (HDF_PLATFORM nodes in file_contexts).
-> Emulator != phone in HDF architecture.
-> Cepheus port starts with CONFIG_DRIVERS_HDF=y in kernel config,
   then drivers/hdf_core compile check against mainline SM8150 tree.
-> Platform-layer test on emulator is IMPOSSIBLE by design.
-> QEMU with custom module is the only live kernel-side test path.
