2. ТЕКСТ ОШИБКИ bm ПОЛУЧЕН
═══════════════════════════════════════════════════════════════════════

При запуске bm install с выводом в файл и последующим cat в консоль
(без убийства процесса) в консоли видно ровно:

    error: failed to execute your command.

(это единственный вывод; bm падает в catch-блоке, как мы выяснили
 статически в круге 34). Причина исключения по-прежнему неизвестна:
 нужно поймать тип исключения/нить hilog.

═══════════════════════════════════════════════════════════════════════
3. ЧИСТЫЙ REBOOT ИЗ ГОСТЯ НЕДОСТУПЕН
═══════════════════════════════════════════════════════════════════════

Попытка сохранить состояние /data чисто:
    /system/bin/sync
    echo 1 > /proc/sys/kernel/sysrq        -> rc=1
    echo b > /proc/sysrq-trigger           -> rc=1
    /system/bin/reboot -p                  -> AVC denied (permissive),
                                              ребута НЕТ, гость жив
=> sysrq/reboot из bmrun не работают (нет прав). QEMU по-прежнему
   убивается SIGTERM, часть данных /data теряется.

НО: каталог /data/diag после прогонов СУЩЕСТВУЕТ (иногда), значит
часть данных всё же доезжает до диска.

═══════════════════════════════════════════════════════════════════════
4. АВТОМАТИЧЕСКИЙ ЦИКЛ ЗАПУСКОВ
═══════════════════════════════════════════════════════════════════════

Создан /home/kharki/loop_runs.sh: до 3 прогонов подряд (каждый ~25 мин),
пересборка образа, запуск, проверка "BMRUN INSTALL_OK" в cur.log.
При успехе: сохраняет success_run.log + в loop_result.txt пишет BMRUN-строки
и блок HILOG (фильтрованные hilog-строки после aa start).
Первый прогон (00:09-00:35) успеха не дал, второй идёт.

Кроме того, bmrun.sh теперь при успехе установки сразу делает
  aa start -b com.huawei.hmos.slassistant -a SuperLauncherMainAbility -m phone
и печатает в консоль:
  - "AA_MAIN"/"AA_MAIN_END"
  - "HILOG-BEGIN ... HILOG-END" (grep hilog по fail/error/StartAbility/
    permission/denied/ability, tail -70)
  - "PS"/"PS-END" (ps -A | grep slassistant)

5. ПЛАН

     `ls /data/app/el1/100`, `account -l` (если есть).
